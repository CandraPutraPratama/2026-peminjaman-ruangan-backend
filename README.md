# 2026-peminjaman-ruangan-backend

## Deskription
Sistem backend profesional yang dirancang khusus untuk mengelola peminjaman ruangan di lingkungan kampus secara terpusat. Proyek ini berfokus pada efisiensi pemantauan status dan akurasi data peminjaman agar tidak terjadi miss atau double-booking.

## Main Features
- Pencatatan Peminjaman: Sistem entry data peminjaman yang valid dan struktur.
- Approval System: Manajemen status peminjaman secara real-time (Approved/Rejected)
- Audit Trail & History: Penelusuran riwayat peminjaman yang detail untuk transparansi data.

## Tech Stack
- Framework: ASP.NET Core
- Language: C#
- Database: SQL Server
